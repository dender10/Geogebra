# GeoGebra — побач математику

Навчальний сайт українською для короткої презентації GeoGebra класу. Містить опис сервісу, переваги й обмеження, покрокову демонстрацію, інтерактивну лабораторію функцій та завдання для класу.

## Запуск

Без збірки та встановлення залежностей. У каталозі проєкту:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Відкрийте сайт на порту 8000 у своєму браузері. Також можна відкрити `index.html` безпосередньо. Цей файл самодостатній: стилі та JavaScript вбудовані, тому для перегляду або передачі достатньо одного HTML-файлу. `style.css` та `app.js` залишені як окремі вихідні файли; якщо змінюєте їх, оновіть відповідні вбудовані блоки в `index.html`.

Лабораторія побудована на Canvas і працює без зовнішніх бібліотек. Шрифт Manrope завантажується з Google Fonts; якщо він недоступний, використовується Arial. Посилання на оригінальний GeoGebra потребують інтернету.

Сайт є незалежним навчальним проєктом, а не офіційним продуктом GeoGebra.
